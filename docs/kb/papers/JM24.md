# JM24

## At A Glance

`JM24` provides AGM/GGM transfer context. It motivated the former handle-table interface;
the current representation-based interface instead cites [FKL18](FKL18.md).

## What ArkLib Uses From This Paper

- Background for comparing the former handle model with the explained-value interface in
  `ArkLib/AGM/Interaction.lean`.
- Context for how algebraic-group-model proofs may relate to more generic computation models.

## Main ArkLib Touchpoints

- `ArkLib/AGM/Interaction.lean` defines certified explained-value adversaries.
- [AGM guide](../../wiki/algebraic-group-model.md) documents the model change and its limits.

## Version Notes

- `JM24` is background, not a line-by-line theorem target.
- See [FKL18](FKL18.md) for the current interface's primary reference.

## Known Divergences From ArkLib

- The current AGM interface proves representation validity of execution, not the paper's
  AGM/GGM transfer results.

## Open Formalization Gaps

- No equivalence theorem connects the removed handle-table interface to the replacement.
- Computational efficiency and AGM/GGM transfer remain outside this interface.
